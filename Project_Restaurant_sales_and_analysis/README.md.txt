# 🍽️ Restaurant Sales Analysis Project

A complete sales dashboard for a restaurant using **PostgreSQL** and **Power BI**.

## Project Features
- Sales Tracking
- Menu Performance Analysis  
- Branch-wise Performance
- Customer Insights
- Interactive Power BI Dashboard

## Technologies Used
- PostgreSQL
- PL/pgSQL
- Power BI

## How to Run This Project

### 1. Database Setup
1. Open pgAdmin
2. Create database `restaurant_db`
3. Run files in this order:
   - schema.sql
   - master_data.sql
   - sample_data.sql
   - procedures.sql

### 2. Power BI Setup
1. Open `Restaurant_Sales_Analysis.pbix` file
2. Refresh the data
